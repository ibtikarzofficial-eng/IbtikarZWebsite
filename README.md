# IbtikarZ
Static, SEO-first business website for Cloudflare Pages.

- No build step required.
- Cloudflare Pages Functions handle `/api/lead`.
- D1 provides durable lead storage.
- Optional Resend/webhook notification support.
- GA4 and Clarity load after consent.
- Existing valuable 3D URLs are preserved.

See `CLOUDFLARE-DEPLOY.md` before going live.
